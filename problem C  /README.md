# Payable Interface - Standard Rental

## Aim

To create an interface `Payable` with a method `calculateCharge()` and implement it in the `StandardRental` class.

## Description

This Java program demonstrates the use of an **interface**.

The `Payable` interface contains the method `calculateCharge()`.

The `StandardRental` class implements the `Payable` interface and calculates the total rental charge using:

**Total Charge = Rental Days × Daily Rate**

## Program Structure

* `Payable` – Interface containing `calculateCharge()`.
* `StandardRental` – Class that implements the `Payable` interface.
* `Main` – Creates a `StandardRental` object and displays the total charge.

## Input

* Rental days = 5
* Daily rate = ₹500

## Output

```text
Rental Days: 5
Daily Rate: ₹500
Total Charge: ₹2500.0
```

## Concepts Used

* Java Interface
* Interface Implementation
* Method Overriding
* Classes and Objects
* Constructor
* Arithmetic Operations

## Conclusion

Thus, the `Payable` interface was created and successfully implemented in the `StandardRental` class to calculate the total rental charge.
